1. What is useEffect in React? useEffect is a React Hook used to handle side effects in your component. Side effects = things that happen outside normal UI rendering Examples: Fetching data from API Updating DOM manually Setting timers Subscriptions Basic Syntax: useEffect(() => { // code (side effect) }, [dependencies]); What is Dependency Array? Dependency array = the second parameter in useEffect It controls WHEN the effect runs useEffect(() => { // code }, [dependency1, dependency2]); 3. What is WITHOUT Dependency Array? If you write useEffect like this: useEffect(() => { console.log("Runs every render"); }); No dependency array Runs every render Can cause performance issues 4. Types of Dependency Usage 1. Empty Dependency [] useEffect(() => { console.log("Runs only once"); }, []); Runs only once (on mount) 2. With Dependency [value] useEffect(() => { console.log("Runs when value changes"); }, [value]); Runs when value changes 3. Without Dependency useEffect(() => { console.log("Runs always"); }); Runs every render 5.What is Fetch? fetch is a JavaScript function used to get data from an API (server) Basic Syntax: fetch("https://api.example.com/data") .then(res => res.json()) .then(data => console.log(data)); 6.
